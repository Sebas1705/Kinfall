# Game Hub Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a common game-selection screen (the hub) as the first screen of the web page and the Android app, with Kinfall playable and two "coming soon" cards.

**Architecture:** A platform-neutral game registry in `packages/core`, a sixth console screen (`hub`) in the shared layout contract, one web screen and one Android screen that render the registry. Kinfall's own flow is untouched; the hub sits in front of its title screen.

**Tech Stack:** TypeScript, Vitest (core, web), Playwright (web e2e), Expo SDK 58 / React Native 0.88 with Jest (mobile), Vite.

**Spec:** `docs/superpowers/specs/2026-11-23-game-hub-design.md` (console contract: `docs/superpowers/specs/2026-11-22-console-layout-design.md`).

## Global Constraints

- Repo text, code, comments, docs, commits in English; UI strings in Spanish and English (es/en parity).
- Commits use the configured identity; no `Co-Authored-By`, no "Generated with", no trailers; never `--no-verify`.
- `packages/core` imports no DOM or React Native modules (`packages/core/tests/platform-neutral.test.ts` enforces it).
- Goldens (battle `a04cb050`, run `e976957e`, art `ab7da2e5`) stay byte-identical: no golden updates.
- Console contract: no page scroll at 640x360 and 360x640 at text scale 1.0 and 1.3 for the hub; beyond `MIN_BUDGET` the fallback mode scrolls only the primary area.
- Touch targets 48 dp (Android) / 44 px (web); focus order follows reading order; every control has an accessible name.
- Storage key for the last game: `kinfall.lastGame` (web localStorage and Android AsyncStorage). Existing keys (`webgames.*`) do not change.
- Never run `playwright install`; web e2e runs on the installed `msedge` channel locally (`--project=chromium` etc. as `apps/web/playwright.config.ts` defines).
- Version `0.4.0` in `apps/mobile/app.json`; do not tag, push or distribute (owner decisions).

## Review Focus

- Stored last game is garbage, missing, or a "soon" game (e.g. `simulator`): the hub focuses Kinfall.
- Storage unavailable (web `defaultStorage()` is null or throws, AsyncStorage rejects): the hub still renders and plays Kinfall.
- Activating a "soon" card does nothing but say it is not available (announced), and focus never gets trapped.
- Text at 130% and at 200% (fallback): every card and the Play button stay reachable by scrolling; nothing is clipped.
- Language switched while the hub is open: names, taglines and button labels update and the focused card is kept.
- Old deep links: `?seed=…`, `?mode=battle` and `?game=kinfall` reach Kinfall as before; `?game=unknown` shows the hub.
- Android Back from `Title` returns to the hub; Back on the hub exits the app; a saved run is still offered by Kinfall's Continue.

### Task 2: Web hub screen and routing

**Files:**

- Test: `apps/web/tests/view/hub.test.ts`, `apps/web/tests/platform/lastGame.test.ts`

**Interfaces:**
- Consumes: Task 1 registry, strings and `gameFromSearch`.
- Produces:
  - `readLastGame(storage: StorageLike | null): unknown` and `writeLastGame(storage: StorageLike | null, id: GameId): void` — never throw; null or throwing storage reads `undefined` and writes nothing.
  - `renderHub(root: HTMLElement, props: HubProps): void` where `HubProps = { focused: GameId; onPlay(id: GameId): void; onFocus(id: GameId): void; onSoon(name: string): void }`. Each game is a radio-like card (`role="radiogroup"` with `role="radio"` cards, `aria-checked`, roving tabindex, arrow keys move focus, Enter/Space plays the focused game); a "soon" card is `aria-disabled="true"` and selecting it calls `onSoon`; a separate `Play` button plays the focused game.
  - `startRunPage(entry: 'hub' | 'kinfall')`: `main.ts` picks `'kinfall'` when `gameFromSearch(location.search)` is non-null, else `'hub'`. The hub is the new default; the `#hud-games` ("Games") button is visible only on the Kinfall title and calls the hub back.
