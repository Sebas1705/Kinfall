# webgames

`webgames` is a placeholder name for a TypeScript browser-game project: a deterministic game engine plus a creature roguelike built on top of it.

## Development

```sh
npm install
npm run dev        # start the Vite dev server
npm test           # run unit tests (Vitest)
npm run typecheck  # strict TypeScript check
npm run build      # production build into dist/
```
